# FlyAlloc

**果蝇连接组启发的资产配置与神经活动可视化实验。**

[English](README.md) · **简体中文**

[快速开始](#快速开始) · [工作原理](#工作原理) · [文档](#文档)

FlyAlloc 探索果蝇连接组约束的神经策略如何将市场信号与组合状态映射为资产配置。项目结合带记忆的图网络与交互式回放，将持仓、神经活动和收益变化放在同一条决策时间轴上观察。

## 快速开始

下载源码，在项目目录打开终端。网页只需要 **Python 3.10+**，无需安装额外依赖。

```bash
# macOS / Linux
python3 serve.py start
```

```powershell
# Windows
py -3 serve.py start
```

打开终端显示的地址，通常为 **http://127.0.0.1:8080/**。随包演示可在本地运行，无需外部服务；其中的虚构资产和合成数值用于体验界面，不执行研究模型。查看真实研究记录时，可按[运行说明](docs/RUNNING.md)导入经授权的本地数据包。

## 工作原理

![FlyAlloc 模型结构：各自独立的图网络与记忆、输出集成及组合反馈](docs/assets/architecture.png)

模型将 **308 维市场特征、4 项账户状态和 8 项持仓权重**映射到 **384 个聚合节点、9,377 条连接**的图网络。三次传播与三种记忆时间尺度为每个策略形成 1,152 维状态。两个独立参数化的策略对输出 logits 取平均，softmax 决定七只股票间的分配，sigmoid 决定总股票仓位，其余保留为现金。

研究设置每五个已观测交易日调仓，收盘后决策、下一交易日开盘按复权价格代理执行，每边交易成本为 5bp。网页按记录的决策时间同步展示配置、活动和收益曲线；身体动作与脑图空间布局为解释性示意。检查点、评估设置和结果口径见[模型卡](MODEL_CARD.md)。
