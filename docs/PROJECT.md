# 项目介绍

## GitHub About

**Name**：FlyAlloc

**Description**：Connectome-inspired asset allocation with interactive neural-state visualization.

**中文介绍**：果蝇连接组启发的资产配置实验，以交互式网页展示组合决策、神经活动和收益变化。

**建议 Topics**：`connectomics`、`neural-networks`、`asset-allocation`、`scientific-visualization`、`pytorch`、`threejs`、`research`

## 简介

FlyAlloc 探索生物连接组约束如何用于资产配置网络。它将市场与账户信息映射到聚合的果蝇神经连接图，通过图传播与多时间尺度记忆形成组合状态，再输出股票配置和现金比例。

项目提供可本地运行的网页，把配置决策、网络活动和收益变化同步到日期时间轴。公开演示采用虚构资产和人工生成的数值，便于无需行情授权即可体验界面；经授权的研究数据可在本地导入、重放和校验。

## 介绍时的准确表述

- 使用真实连接组派生的简化网络，384 个聚合节点不是完整果蝇大脑。
- 研究模型输出组合配置，三维果蝇的行走是解释性动画。
- 可复现固定模型推理、决策账本及神经状态。
- 当前历史结果不能证明生物拓扑优于随机图或具有稳定投资优势。
